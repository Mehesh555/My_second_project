# 🏥 Hospital Details Dashboard (Power BI)
## 📌 Overview

This project showcases an interactive Hospital Details Dashboard built using Power BI to analyze hospital operations, including doctors, staff, patients, and income trends. It provides meaningful insights to support hospital management and decision-making.

# 🎯 Objectives
    Monitor doctor and staff distribution
    Analyze patient count and admissions
    Track monthly income trends
    Understand department-wise performance
    Visualize room capacity and hospital resources

# Key Visuals:
    📈 Income by Month (Line Chart)
    🥧 Doctor & Staff Distribution by Department
    📊 Patient Count by Medicine
    📉 Staff Hiring Trends (Quarterly)
    📊 Patient Admissions Analysis
    📊 Department-wise Doctor Count    

# 🎨 Key Highlights
    📌 Interactive Slicers (Department filtering)
    🔄 Drill-through functionality for detailed analysis
    📊 Multiple chart types for better insights
    🎯 KPI cards for quick summary
    🧭 Clean and user-friendly dashboard design    

# 📈 Insights
    Some departments handle higher patient loads
    Monthly income shows fluctuating trends
    Room types like General & ICU have higher usage
    Staff and doctor distribution varies across departments   

# 📌 Use Cases
    Hospital Management Analysis
    Resource Planning
    Patient Flow Monitoring
    Financial Performance Tracking    

# 🧾 Conclusion

This dashboard demonstrates how Power BI can convert hospital data into actionable insights, helping improve operational efficiency and strategic planning.
